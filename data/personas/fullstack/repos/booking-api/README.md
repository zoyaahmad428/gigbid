# booking-api

Booking platform for a fintech business.

## What it does
Bookings came in by phone and email and were often double-booked. This is the code from when I built a React booking widget that embeds on the existing site.

## Stack
Django REST API and availability engine; Django, React, PostgreSQL, REST API.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: moved 62% of bookings online within two months.
