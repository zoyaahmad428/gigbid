# chat-service-e-commerce

Real-time messaging feature for a e-commerce marketplace.

## What it does
Buyers and sellers had no way to talk inside the product. This is the code from when I stored conversations with moderation hooks.

## Stack
WebSocket gateway and message store; Node.js, React, TypeScript.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: 51% of transactions started with an in-app message after launch.
