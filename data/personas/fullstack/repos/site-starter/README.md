# site-starter

Fast marketing site and CMS for a media company.

## What it does
The old site was slow, hard to edit and ranked poorly. This is the code from when I connected a headless CMS so the marketing team could publish alone.

## Stack
Next.js site with CMS; Next.js, React, Tailwind CSS, HTML/CSS.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: raised Lighthouse performance from 42 to 98.
