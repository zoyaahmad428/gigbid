# ops-admin-hospitality

Internal admin tool for a hospitality operations team.

## What it does
Operations ran on shared spreadsheets with no access control. This is the code from when I built list, filter and bulk-edit screens in React.

## Stack
Django admin extensions and React screens; Django, React, PostgreSQL.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: replaced 10 spreadsheets.
