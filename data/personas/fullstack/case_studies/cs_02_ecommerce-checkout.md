# Checkout and subscriptions rebuild for a media store

**Client:** media company  
**When:** 2025-09 to 2025-10  
**Engagement:** hourly

## Situation
Checkout errors and a manual billing process were losing orders.

## What I did
- Rebuilt checkout with Stripe Payment Intents and webhooks.
- Added subscription plans with proration.
- Wrote end-to-end tests for every payment path.

## Outcome
- Raised checkout conversion by 6%.
- Cut failed payments by 20%.

## Stack
React · Node.js · Stripe · TypeScript
