# Multi-tenant SaaS dashboard for a legal services startup

*Legal services client · 2023-03 · 14 weeks · fixed-price*

The founders had a prototype that could not handle more than one customer. I was brought in to fix that.

I started by working out what good looked like with the client, then rebuilt the frontend in Next.js with TypeScript. Next I added tenant-scoped data access in the API and the database. Finally, I set up role-based access and audit logging.

The result: I onboarded 17 paying customers in the first quarter, and cut dashboard load time from 8s to 2s.

Tools: TypeScript, Next.js, React, Node.js, PostgreSQL.
