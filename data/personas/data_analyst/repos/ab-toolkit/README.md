# ab-toolkit

A/B test design and analysis for a non-profit product team.

## What it does
Tests were stopped early and results were read from dashboards. This is the code from when I analysed results with confidence intervals and guardrail metrics.

## Stack
power and analysis helpers; Statistics, Python, SQL.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: reviewed 12 past tests and found half were underpowered.
