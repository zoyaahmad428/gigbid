# ops-kpis

Operations KPI dashboard in Tableau for a real estate company.

## What it does
Managers could not see delays until customers complained. This is the code from when I built KPI views for delay, throughput and backlog.

## Stack
extract queries and calculated fields; Tableau, SQL, Data Visualization.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: cut average delay by 21% after the first quarter.
