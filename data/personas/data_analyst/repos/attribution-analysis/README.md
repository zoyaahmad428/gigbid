# attribution-analysis

Marketing channel attribution analysis for a manufacturing brand.

## What it does
The team could not say which channels drove sales. This is the code from when I compared last-click with a position-based model.

## Stack
notebooks and SQL; SQL, Python, Statistics.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: found that 27% of spend went to channels with no measurable return.
