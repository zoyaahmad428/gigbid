# cohort-analysis

Customer cohort and retention analysis for a media app.

## What it does
Growth looked healthy but revenue was flat. This is the code from when I measured retention and revenue per cohort.

## Stack
cohort SQL and charts; SQL, Python, Data Analysis.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: found a 50% drop-off at one onboarding step.
