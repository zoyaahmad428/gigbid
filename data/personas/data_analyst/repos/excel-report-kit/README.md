# excel-report-kit

Excel reporting automation for a manufacturing finance team.

## What it does
A weekly report took a full day of copy-paste across workbooks. This is the code from when I replaced manual lookups with structured references.

## Stack
Power Query steps and helper SQL; Excel, Data Analysis.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: cut the weekly report from 9 hours to 2.
