# sales-model-b2b-saas

Sales performance dashboard for a B2B SaaS company.

## What it does
Leadership got sales numbers from three teams that never agreed. This is the code from when I modelled the data in SQL into a clean star schema.

## Stack
SQL views and DAX measures; SQL, Power BI, Data Visualization.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: replaced 8 manual weekly reports.
