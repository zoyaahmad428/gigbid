# client-reporting

Self-serve reporting in Looker Studio for a hospitality agency.

## What it does
Account managers asked the analyst for the same reports every week. This is the code from when I designed Looker Studio templates per client type.

## Stack
BigQuery reporting views; Looker, BigQuery, SQL.

## Run
```bash
make install
make run
```

Client data is not included. Results in production: cut analyst report requests by 74%.
