# Analytics warehouse with dbt for a media startup

**Client:** media company  
**When:** 2024-03 to 2024-05  
**Engagement:** hourly

## Situation
Every analysis started with an hour of cleaning raw tables.

## What I did
- Set up staging, intermediate and mart models in dbt.
- Added tests for keys, nulls and accepted values.
- Documented each model so non-analysts could use the marts.

## Outcome
- Built 38 tested models.
- Cut time to answer ad-hoc questions by about 49%.

## Stack
dbt · SQL · BigQuery · ETL
